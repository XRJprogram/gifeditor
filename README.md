# GIF editor - QQ 表情动图衍生工坊

专为 QQ 表情包二次创作与衍生动图制作设计的轻量级可视化节点蓝图编辑器 (UE5 Blueprint-Style Node Graph)。
数据源直连 QFace / QQNT 表情库（全量收录纯动态表情与超级表情，剔除静态与无效项）。免安装、纯前端运行，通过节点连线即可将多个 QQ 表情进行对称、缝合、变形、变速、调色与区间裁剪。

---

## 核心特性

### 1. 工业级可视化节点蓝图系统
- 界面采用暗色 Slate 蓝图主题设计，配备坐标网格背景，支持平滑滚轮缩放与鼠标拖拽平移。
- 三次贝塞尔曲线连线机制：节点输出端支持一对多分路输出，输入端采用单连线约束。
- 换线与解绑交互：拖拽已连线的输入端可快速换接到其他引脚；连回原引脚或拖向空白处释放即可删除连线。
- 全局终点约束：全画布仅允许放置一个终点输出节点，只有连入终点输出的流图分支才会触发最终计算与导出，杜绝中间态混淆。
- 响应式 DAG（有向无环图）拓扑求值引擎：调节任意参数滑块或切换输入表情时，系统自动反向追踪依赖并进行局部增量求值。
- 自定义模态对话框：清空蓝图等危险操作采用内置工业风二次确认弹窗，支持遮罩点击与 Esc 键退出，彻底告别浏览器原生弹窗。

### 2. 精简丰富的二创函数库

#### 对称镜像 (Symmetry)
- 双对称：单个节点内置分段选项卡，一键切换「保留左侧 / 保留上半 / 保留右侧 / 保留下半」并镜像覆盖另一侧。
- 四对称：单个节点内置分段选项卡，一键切换「保留左上 / 保留右上 / 保留左下 / 保留右下」进行四向万花筒镜像。

#### 画面融合与排布 (Blend & Splice)
- 阴阳脸缝合：接入两个不同的表情，自定义中线比例与平滑过渡，无缝生成双表情阴阳脸。
- 画中画叠加：支持背景底图与前景覆盖层叠加，提供位置 X、位置 Y、缩放尺寸、旋转角度与不透明度精准微调。
- 水平/垂直并排：支持将两个表情进行水平或垂直并列排布拼接。

#### 色彩与滤镜 (Color & Filters)
- 色彩微调：色相旋转 (0~360度)、饱和度、亮度、对比度与反色控制。
- 滤镜预设：内置灰度、反色、复古、赛博朋克、高反差、暖调、冷调等常用滤镜。
- 透明通道保护：色彩计算与滤镜渲染严格过滤 Alpha 为 0 的背景透明像素，杜绝底色污染或红晕泛边。

#### 帧数控制与变速 (Frame & Timing)
- 播放变速：独立变速节点，支持 0.1x 至 5.0x 倍速播放调节。
- 帧数区间：采用单一连续调节条搭配双调节端（双端范围滑块），支持在 0% 至 100% 相对时间轴内截取任意帧段，高亮选区支持整体拖动平移，并提供「前 50% / 后 50% / 中 50% / 全段」快捷预设。
- 帧数约束：提供最大帧数上限限制（16/24/32 帧等）、抽帧跳步 (Step 隔帧抽取) 与自定义帧延时控制。
- 往复循环：自动生成无缝乒乓往复动画序列。
- 全片倒放：反转动画帧序列。

#### 像素级扭曲变形 (Warp)
- 包含凸透镜膨胀 (Bulge)、凹透镜捏脸 (Pinch)、正弦波浪 (Wave) 与果冻形变 (Squash) 四种空间扭曲算法。

## 实时预览与出品控制

- 独立实时播放器：按帧延时循环播放当前蓝图输出的动态效果，支持 1x/2x/3x 视口缩放切换。
- 精简控制栏：单行集成矢量图标控制按钮，包含播放/暂停、单帧步退、单帧步进以及一键复制当前帧图片。
- 性能与状态指示：实时显示动画总帧数与单次 DAG 计算耗时 (ms)。

---

## 导出与画质保障

- 原图尺寸导出：默认采用 1:1 原始尺寸导出，彻底杜绝缩放插值引起的画面模糊。
- 调色板与透明边缘优化：采用分级 Alpha 阈值二值化与高精度调色板算法，彻底消除透明背景边缘的红色杂边与光晕。
- 规范检测：导出面板自动估算输出文件体积，检测是否符合表情文件标准。
- 导出与分享：支持直接下载 GIF 动图到本地，支持按住动图直接拖拽到 QQ/微信等聊天窗口发送（免保存且保留完整透明动态），支持将动图富文本写入剪贴板。
- 工程备份：支持将当前编辑的节点拓扑与参数导出为操作序列 JSON 文件，并随时导入复原。

## 快速启动

### 方式一：直接双击运行（无需环境配置）
1. 解压或克隆本项目文件夹。
2. 直接双击 `index.html`，即可在任意主流现代浏览器（Chrome、Edge、Firefox 等）中离线使用全部功能。

### 方式二：本地静态服务运行
如需使用本地 HTTP 服务运行，可在项目根目录下执行：
```bash
# 启动内置简易 HTTP 服务
node server.js
```
启动后在浏览器中访问：`http://localhost:3000`

## 预设方案

页面顶部导航栏提供经典二创蓝图预设，点击即可一键载入：
1. 双对称左侧镜像：`QQ 表情 (吓)` -> `双对称 (保留左侧)` -> `终点输出`
2. 阴阳脸缝合：`表情 A (微笑)` + `表情 B (发怒)` -> `阴阳脸缝合` -> `终点输出`
3. 大头膨胀与帧数约束：`QQ 表情 (笑哭)` -> `凸透镜变形` -> `帧数约束 (16帧)` -> `终点输出`
4. 往复循环：`QQ 表情 (汪汪柴犬)` -> `往复循环` -> `终点输出`

## 项目结构说明

```
gifeditor/
├── index.html                   # 主应用入口与界面布局
├── server.js                    # 本地简易静态 HTTP 服务器
├── package.json                 # 项目依赖配置
├── README.md                    # 项目说明文档
├── css/
│   ├── style.css                # 主界面布局、侧边栏、模态框与暗色工业风主题样式
│   └── blueprint.css            # 蓝图画布、网格背景、节点流图、连线与双端范围滑块样式
├── lib/
│   └── gif-engine.bundle.js     # 纯前端离线编解码引擎 (集成 apng-js, omggif, gifenc)
├── data/
│   ├── qq_emoji_index.json      # 官方表情完整索引原始数据
│   └── emoji_catalog.json       # 纯动态表情与超级表情检索目录
├── assets/
│   └── qq_emoji/                # 本地预存的核心表情动图与预览资产
├── scripts/
│   └── fetch-qq-emojis.js       # 表情数据抓取与同步脚本
└── js/
    ├── core/
    │   ├── qq-emoji-service.js  # QQ 表情加载、缓存与搜索服务
    │   ├── gif-decoder.js       # APNG / GIF 动态帧解析引擎
    │   ├── gif-encoder.js       # 专用高精度调色板与透明边缘二值化 GIF 编码器
    │   ├── function-library.js  # 纯函数算法库 (对称、缝合、滤镜、变速、区间截取等)
    │   └── warp-engine.js       # 空间像素双线性插值扭曲引擎
    ├── blueprint/
    │   ├── node-definitions.js  # 节点参数、元数据与求值逻辑定义
    │   ├── graph-model.js       # 拓扑数据模型与 DAG 拓扑排序求值引擎
    │   └── blueprint-canvas.js  # 蓝图视口渲染、连线路由与双端滑块组件交互
    └── app.js                   # 状态协调、播放器驱动、模态框交互与事件绑定
```
